# Python Checkpoint

This project contains Python exercises covering lists, tuples, dictionaries, and sets. It includes list multiplication, tuple sorting, dictionary merging, generating squares, and basic set operations such as iteration, adding, and removing elements.

## How to Run

1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python checkpoint.py
```

**Note:** The program asks the user to enter an integer for Question 4.
